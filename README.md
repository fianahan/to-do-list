# To-Do List

A Python-based command-line application for managing daily tasks efficiently.

## Overview

This project was built to practice core Python programming concepts and create a functional task manager with a simple user interface. It allows users to add, view, complete, delete, and save tasks using local file storage.

## Features

- Add new tasks
- View current tasks
- Mark tasks as completed
- Delete tasks
- Save tasks to a JSON file
- Load saved tasks when the application starts

## Tech Stack

- Python 3
- JSON

## Run the Project

```bash
python todo.py
```

## Example Menu

```text
1. Add task
2. View tasks
3. Complete task
4. Delete task
5. Save tasks
6. Exit
```
